# HumanAim Analytics Platform

Professional aim training analytics platform using Computer Vision and Windows Raw Input API.

## Features

- Mouse movement capture at 1000Hz+ (Raw Input API)
- Multi-color target detection (OpenCV)
- Comprehensive biometric analysis
- Automatic player style classification
- Professional chart reports (300 DPI)

## Supported Games

| Game | Platform | Free |
|------|----------|------|
| Aim Lab | Steam | Yes |
| KovaaK's | Steam | No |
| 3D Aim Trainer | Steam | Yes |
